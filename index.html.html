XYZ Frames Lab

Robotics I · Lecture 2: Spatial Description

What to try
  1. “Frame” tab: move and rotate the frame and watch the matrix R. Each column is the direction of one frame axis.
  2. Switch between “About world axes” and “About frame axes” using the same angles; the results differ.
  3. “Compare A & B” tab: see T = A⁻¹·B, the pose of B as seen from A.
  4. “Point” tab: q is fixed inside the frame while P moves in the world.
  5. Type exact values (angles in degrees) in the boxes next to the sliders.
